# Backup — `abilities.md` as it stood before the 2026-08-06 rollout

⚠ **NOT KNOWLEDGE. Do not read these as current, do not cite them, do not grep them
for facts.** They are a safety copy, kept only so a real button recorded by hand can
be recovered if the rollout dropped it.

One file per spec, named `<class>-<spec>.md`, copied from
`knowledge/classes/<class>/<spec>/abilities.md` immediately before each was rewritten
into the two-section shape (§A real buttons the generated inventory cannot see, §B
encountered-and-believed-invalid).

**Why a backup at all:** the pre-rollout files were the *only* record of several real
pressed buttons — `Devour`, `Pierce the Veil`, `Templar Slash`, `Void Volley`,
`Heroic Strike` — because runtime override / proc-replacement buttons live in no
spec-keyed DB2 table. Losing that text loses the abilities.

**Why they are not knowledge:** their cast times, cooldowns and resource costs were
authored from Tier-3 guides and are superseded by the generated
`ability-inventory.md`, which is DB2-pinned to `12.0.7.67808`. Roughly 170 of the
KB's `@verify-ingame` markers lived in these files, most of them flagging a guessed
number rather than a genuine in-game question.

**Delete this directory** once the rollout is verified and you are confident nothing
was lost.
