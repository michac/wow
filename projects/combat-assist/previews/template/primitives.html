Primitives the declared style

Every primitive the shelf declares, as a live swatch — including the ones no scenario on any spec page exercises. This is one page and not one per spec because a primitive is not a claim about a rotation: the style vocabulary is byte-identical on all of them, and only the roster it borrows art from differs. A shelf edit always lands somewhere visible here.

Each swatch says what the primitive tells the player first, and how it is drawn second. If a swatch's caption only describes pixels, it is not finished — you can already see the pixels.
