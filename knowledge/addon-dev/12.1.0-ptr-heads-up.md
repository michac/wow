## Three things this file got wrong, recorded because they were believed

The 2026-08-04 draft warned that its own list came through a summarizing fetch and
told the reader to re-pull exact signatures before authoring. That warning paid for
itself three times, and the corrections are worth keeping because each is the kind of
error that reads as authoritative:

1. **`Enum.ForbiddenAspect` has 11 members, not 6.** The six were the ones announced
   in one mid-PTR post; the shipped enum is a bitfield 1…1024 that also carries
   `SetToDefaults`, `ScriptBindings`, `ChangeAnimationTarget`, `RemoveSecretAspects`
   and `ChangeParent`.
2. **`<KeyValue>` takes `type="local"`, not `source="local"`.** `source` is the
   `<Mixin>` attribute and belongs to a different schema enumeration. The draft's form
   is a schema error.
3. **`SecretPayloads` did not grow, and `UNIT_AURA` is still not on it.** The draft
   named "`SecretPayloads = 7` … `UNIT_AURA` is not in the list" as the concrete stale
   anchor. That list is *unchanged* at seven; the secret payload arrives by a second,
   previously unused route — a `Secret` predicate applied to the event entry itself.
   An audit written to the draft's expectation would have looked in the wrong place.

## What was NOT done on patch day

Named here so nobody assumes otherwise, and so the follow-ups have one home:

- **Nothing was run in the client.** Every `[client]` tag in the subtree is a 12.0.7
  measurement and was deliberately **not** restamped. Where 12.1.0 makes one doubtful
  the doubt is written beside it.
- **`file:line` locators were not re-resolved.** Unstamped ones are still
  12.0.7.68887; `@12.1.0`-stamped ones were read on the new tree. Corpus *counts* were
  all re-derived.
- **`BlizzardInterfaceResources` was not re-pulled** — every `[T2 res]` row in the
  subtree (global strings, CVar dump, `Resources/Events.lua`, `WidgetAPI.lua`'s
  inheritance graph) is still 12.0.7.68256.
- **`wowkb.uiapi` still indexes the 12.0.7 checkout**, so its `stats` disagree with
  the topic files by design (`sources.md` §1.1a).
- **`cooldown-manager.md` §2, §3 and §7 were not re-derived**, only annotated. The CDM
  changed more than any other system here.
- **The third-party clone census and the live-install inventory were not re-taken**,
  so every `[T3]` and `[T1 obs]` figure in the subtree predates the patch.
